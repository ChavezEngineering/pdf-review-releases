# CE PDF - downloads

Downloads of **CE PDF** (called PDF Review up to 0.5.x), the PDF markup app used at Chavez Engineering PLLC.
This repository holds only the finished app and its release notes. No source code is kept here.

**Download:** open [the latest release](https://github.com/ChavezEngineering/pdf-review-releases/releases/latest) and,
under *Assets*, pick `PDFReview-windows.zip` (Windows) or `PDFReview-mac.zip` (Mac, Apple chip).
The zip names keep the old name so installed copies keep updating.

**Windows:** unzip it to a folder you keep (for example in Documents) and run `PDFReview.exe` inside it.
Leave the folder where it is: updates replace it in place.

**Mac:** unzip it and drag `CE PDF.app` into **Applications**, then open it from there (not from Downloads).
The first time, macOS may say it cannot check the app: open **System Settings > Privacy & Security** and click
**Open Anyway**.

Once installed, the app updates itself: **Check for Updates** (top right) asks "Install it now?" when there is a new
version.
